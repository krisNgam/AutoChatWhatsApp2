# AutoChat WhatsApp — compilation GitHub Actions

Ce projet contient un prototype Android et un workflow GitHub Actions pour compiler automatiquement un APK.

## Compilation en ligne
1. Créer un dépôt GitHub.
2. Envoyer le contenu de ce dossier dans le dépôt (y compris `.github`).
3. Ouvrir l'onglet **Actions**.
4. Choisir **Build Android APK**.
5. Cliquer sur **Run workflow**.
6. Une fois terminé, ouvrir l'exécution réussie et télécharger l'artefact **AutoChatWhatsApp-debug**.

Le fichier obtenu est `app-debug.apk`.
